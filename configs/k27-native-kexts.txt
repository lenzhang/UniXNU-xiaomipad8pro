# The native kexts linked into piano's k27 kernel collection (tooling/k27/build-native-image.sh): descriptors in tooling/k27/kext/,
# sources in package/, objects in out/native-kexts/ (docs/native-droidvm-inventory.md).
# Not linked natively (2026-11-11): the VM's NativeVirtioBlock (virtio root), DroidVMEthernet, DroidVMAudio, DroidVMVideo, DroidVMInput
# (virtio devices), DroidVMGpu (stub accelerator: WindowServer dies on it), DroidVMDisplay (virtio scanout; NativeGopDisplay has its
# own nub), NativeAES (no reader natively: no AppleKeyStore, Data unencrypted).
ARMPlatformStandIn   # AppleARMPlatform's classes, which IOMobileGraphicsFamily and its kexts link against
NativeUfs            # UFS root windows + Data store
NativeRamBlock       # the Data disk (RAM seed + changed pages in NativeUfs's store)
NativeGopDisplay     # the display: CPU copy into the GOP framebuffer, and its AppleParavirtGPU nub
PianoA830            # the Adreno 830 GPU (docs/drivers/gpu.md) and its AGXAccelerator; inert without piano-gpu=N (PIANO_GPU=2 adds it)
PianoDwc3            # USB device-mode debug channel (CDC-ACM console); inert without piano-usb=N
PianoInput           # the buttons (power, vol-, vol+) as HID consumer keys; inert without piano-input=N
PianoNullEthernet    # a built-in en0 without hardware: TimeSync (and so WindowServer) needs a built-in interface
PianoPower           # battery gauges, charger port, the DSP charger path; inert without piano-power=N
PianoWifi            # the WCN7860 Wi-Fi on PCIe0, level 1 (read-only survey) only; inert without piano-wifi=N (docs/drivers/wifi.md)
