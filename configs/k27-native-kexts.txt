# The native kexts linked into piano's k27 kernel collection (tooling/k27/build-native-image.sh): descriptors in tooling/k27/kext/,
# sources in package/, objects in out/native-kexts/ (docs/native-droidvm-inventory.md).
# Not linked natively (2026-11-11): the VM's NativeVirtioBlock (virtio root), DroidVMEthernet, DroidVMAudio, DroidVMVideo, DroidVMInput
# (virtio devices), DroidVMGpu (stub accelerator: WindowServer dies on it), DroidVMDisplay (virtio scanout; NativeGopDisplay has its
# own nub), NativeAES (no reader natively: no AppleKeyStore, Data unencrypted).
ARMPlatformStandIn   # AppleARMPlatform's classes, which IOMobileGraphicsFamily and its kexts link against
NativeUfs            # UFS root windows + Data store
NativeRamBlock       # the Data disk (RAM seed + changed pages in NativeUfs's store)
NativeGopDisplay     # the display: CPU copy into the GOP framebuffer, and its AppleParavirtGPU nub
PianoA830            # the Adreno 830 GPU (docs/drivers/gpu.md) and its AGXAccelerator; inert without piano-gpu=N (PIANO_GPU=2 adds it)
PianoBacklight       # the panel backlight (2x KTZ8866 over software I2C, docs/drivers/backlight.md); inert without piano-backlight=N
PianoDpu             # the display processor (docs/drivers/dpu.md): level 1, a read-only survey of the DPU/DSI state; inert without piano-dpu=N
PianoDwc3            # USB device-mode debug channel (CDC-ACM console); inert without piano-usb=N
PianoInput           # the buttons (power, vol-, vol+) as HID consumer keys; inert without piano-input=N
PianoNullEthernet    # a built-in en0 without hardware: TimeSync (and so WindowServer) needs a built-in interface
PianoPower           # battery gauges, charger port, the DSP charger path; inert without piano-power=N
PianoTorch           # the rear torch (PM8550 flash LED, docs/drivers/torch.md): 1 read-only survey, 2 control (read-back, time limit, thermal guard); inert without piano-torch=N
PianoThermal         # SoC temperatures (TSENS), protection, CPU frequency over SCMI (docs/drivers/thermal.md); inert without piano-thermal=N / piano-cpufreq=N; after PianoA830 (its GPU hooks)
PianoTouch           # the NT36532E touch screen (docs/drivers/touch.md); inert without piano-touch=N; after PianoA830 (its GCC lock word)
PianoWifi            # the WCN7860 Wi-Fi on PCIe0 (docs/drivers/wifi.md): 1 survey, 2 power, 3 link, 4 MHI firmware; inert without piano-wifi=N; after PianoA830 (its lock words) and NativeUfs (level 4 reads modem_a)
PianoAudio           # speakers (4 x FS19xx, TDM) and DMICs via the ADSP, level 1 (read-only survey) only; inert without piano-audio=N (docs/drivers/audio.md)
PianoUsbHost         # USB host / Type-C (docs/drivers/usb-host.md): level 1 only, a read-only survey (Type-C state, orientation, DWC3 role, xHCI caps, QMP mux); inert without piano-usbhost=N; PianoDwc3 keeps the controller
PianoVideo           # the video core (SM8750 Iris, docs/drivers/video.md): level 1 only, a read-only survey (video clocks/GDSCs, the core when powered, SMMU 0x1940/0x1947); inert without piano-video=N
PianoSensors         # the ADSP sensor hub (docs/drivers/sensors.md): 1 survey, 2 the FastRPC file service from the ESP pack, 3 the SNS sensor list; inert without piano-sensors=N; after PianoPower (its client contract) and NativeUfs (the ESP)
