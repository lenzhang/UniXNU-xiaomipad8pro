# The native kexts linked into piano's k27 kernel collection (tooling/k27/build-native-image.sh): descriptors in tooling/k27/kext/,
# sources in package/, objects in out/native-kexts/. Only this repository's kexts (the native kext rule, docs/bringup-debugging.md
# §5, enforced by tooling/k27/check-native-kexts.py): none of the VM-era paravirtual kexts (virtio block root, Ethernet, audio,
# video, input, the stub GPU accelerator, the virtio display), and no NativeAES (no reader natively: no AppleKeyStore, Data
# unencrypted).
ARMPlatformStandIn   # AppleARMPlatform's classes, which IOMobileGraphicsFamily and its kexts link against
NativeUfs            # UFS root windows + Data store
NativeRamBlock       # the Data disk (RAM seed + changed pages in NativeUfs's store)
NativeGopDisplay     # the display: CPU copy into the GOP framebuffer, and its AppleParavirtGPU nub
PianoA830            # the Adreno 830 GPU (docs/drivers/gpu.md) and its AGXAccelerator; inert without piano-gpu=N (PIANO_GPU=2 adds it)
PianoBacklight       # the panel backlight (2x KTZ8866 over software I2C, docs/drivers/backlight.md); inert without piano-backlight=N
PianoDpu             # the display processor (docs/drivers/dpu.md): level 1, a read-only survey of the DPU/DSI state; inert without piano-dpu=N
PianoDwc3            # USB device-mode debug channel (CDC-ACM console); inert without piano-usb=N; after PianoA830 (its lock words: the cold start's GCC vote and DRV-2 rail votes)
PianoInput           # the buttons (power, vol-, vol+) as HID consumer keys; inert without piano-input=N
PianoKeyboard        # the keyboard cover (WN8030: keys, touchpad, hall sensor; docs/drivers/keyboard.md); inert without piano-keyboard=N; after PianoA830 (its DRV-2 lock word). Listed 2026-11-12: it was linked only with PIANO_EXTRA_KEXTS, so attend5's and desk1's images had none
PianoNullEthernet    # a built-in en0 without hardware: TimeSync (and so WindowServer) needs a built-in interface
PianoPower           # battery gauges, charger port, the DSP charger path; inert without piano-power=N
PianoTorch           # the rear torch (PM8550 flash LED, docs/drivers/torch.md): 1 read-only survey, 2 control (read-back, time limit, thermal guard); inert without piano-torch=N
PianoThermal         # SoC temperatures (TSENS), protection, CPU frequency over SCMI (docs/drivers/thermal.md); inert without piano-thermal=N / piano-cpufreq=N; after PianoA830 (its GPU hooks)
PianoTouch           # the NT36532E touch screen (docs/drivers/touch.md); inert without piano-touch=N; after PianoA830 (its GCC lock word)
PianoWifi            # the WCN7860 Wi-Fi on PCIe0 (docs/drivers/wifi.md): 1 survey, 2 power, 3 link, 4 MHI firmware, 5 QMI, 6 the copy engine + a passive scan; inert without piano-wifi=N; after PianoA830 (its lock words) and NativeUfs (levels 4-5 read modem_a)
PianoWifiEthernet    # the macOS side of the Wi-Fi path (wifi.md §13.1): en1, built in, link down, with level 6's scan list; matches the resource PianoWifiLink, which only piano-wifi=6 publishes; after PianoWifi
PianoAudio           # speakers (4 x FS19xx, TDM) and DMICs via the ADSP (docs/drivers/audio.md): 1 survey, 2 DSP link (with piano-power=2), 3 macOS devices on a null transport, 4 PRM clocks, 5 amplifiers (powered down), 6 graphs with silence, 7 the tone walk (only with piano-audio-tone=1); inert without piano-audio=N; after PianoPower (its DSP client functions) and NativeUfs (the preset on the ESP)
PianoUsbHost         # USB host / Type-C (docs/drivers/usb-host.md): 1/2 a read-only survey (Type-C state, orientation, DWC3 role, xHCI caps, QMP mux), 3/4 the port manager on PianoPower's USB-C relay (port notifications, 4 our UCSI client; the role switch default off), 5 our own xHCI probe (H5), 6 Apple's xHCI on PianoUsbHostNub (H6, needs PIANO_USBHOST_STACK=1); inert without piano-usbhost=N; after PianoPower (its relay functions); PianoDwc3 keeps the controller (5/6 refuse with piano-usb>=2; 3/4 switch only with both hand-off switches)
PianoVideo           # the video core (SM8750 Iris, docs/drivers/video.md): 1 a read-only survey, 2 power on/off (V1), 3 + PAS 9 with the pinned firmware from the RAM image's addon or the ESP (V2), 4 + its SMMU bank and the HFI handshake (V3); inert without piano-video=N, nothing written below 2; after PianoA830 (its DRV-2 and secure-call lock words) and NativeUfs (the firmware loader's ESP source)
PianoSensors         # the ADSP sensor hub (docs/drivers/sensors.md): 1 survey, 2 the FastRPC file service from the ESP pack, 3 the SNS sensor list, 4 the light and accelerometer streams; inert without piano-sensors=N; after PianoPower (its client contract) and NativeUfs (the ESP)
PianoDp              # USB-C DisplayPort (docs/drivers/displayport.md): level 1 only, read only: D1 a survey (DP controller, QMP DP half, the DPU's DP side, each behind its clock gate), D2 the DSP's port notifications logged (with piano-power=2); inert without piano-dp=N; after PianoPower (its client contract)
PianoBluetooth       # the WCN7860's Bluetooth over QUP2 SE6 "UART14" (docs/drivers/bluetooth.md): 1 survey, 2 power (the rails shared with PianoWifi, BT_EN), 3 UART, 4 controller set-up (firmware from bluetooth_a); inert without piano-bt=N; after PianoA830 (its lock words, the rails helper's words) and NativeUfs (bluetooth_a)
PianoPolicy          # the laptop-class policy (docs/policy.md): cover, keyboard wake, power key, Low Power Mode -> PianoThermal / PianoA830; inert without piano-policy=N; after the drivers it watches (PianoThermal: a library, its breadcrumb)
